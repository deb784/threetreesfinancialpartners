Accessibility Statement

OUR COMMITMENT

ThreeTrees Retirement Partners is committed to ensuring digital accessibility for people with disabilities. We continually improve the user experience for everyone and apply the relevant accessibility standards.

CONFORMANCE STATUS

We strive to conform to the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA standards published by the World Wide Web Consortium (W3C).

ACCESSIBILITY FEATURES

Our website includes the following features:

Navigation:

  • Clear and consistent navigation menu
  • Skip-to-content links
  • Breadcrumb navigation
  • Keyboard-accessible interface

Content:

  • Alternative text for images
  • Descriptive headings and labels
  • Sufficient color contrast
  • Readable font sizes (16px minimum)
  • Clear link descriptions

Forms:

  • Properly labeled form fields
  • Error identification and suggestions
  • Keyboard navigation support
  • Clear instructions

Multimedia:

  • Captions for videos (when applicable)
  • Transcripts for audio content
  • Alternative formats available upon request

Technical:

  • Responsive design for all devices
  • Screen reader compatibility
  • Semantic HTML structure
  • ARIA labels where appropriate

KNOWN LIMITATIONS

  • Third-party embedded content (videos, maps)
  • Legacy PDF documents (being updated)
  • Some dynamically generated content

We are actively working to address these issues.

COMPATIBILITY

Our website is designed to be compatible with:

  • Modern web browsers (Chrome, Firefox, Safari, Edge)
  • Screen readers (JAWS, NVDA, VoiceOver)
  • Keyboard-only navigation
  • Voice recognition software
  • Browser text-size controls

THIRD-PARTY CONTENT

Some content is provided by third parties and may not be fully under our control. We request that vendors meet accessibility standards but cannot guarantee compliance.

  • We will work with you to provide alternative access
